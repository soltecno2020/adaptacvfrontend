## Brand & Style
The design system embodies a forward-looking aesthetic tailored for a creative technologist and visionary digital designer. It merges deep cosmic voids with luminous, refracted energy—balancing precision engineering with ethereal digital artistry. 

The aesthetic fuses **Glassmorphism** with **Futuristic Cyber-Minimalism**:
- **Atmosphere:** Deep space spatial planes punctuated by fluid iridescent refractions, hyper-vibrant focal points, and ambient spectral glows.
- **Personality:** Pioneering, visionary, technically formidable, pristine, and immersive.
- **Emotional Response:** Inspires awe, curiosity, and high technical trust, signaling boundary-pushing craft at the intersection of creative code and dimensional user experience.

## Colors
The palette is rooted in the infinite depth of deep cosmic navy and void blacks, illuminated by hyper-saturated chromatic primaries that mimic prismatic light passing through frosted synthetic crystal.

### Semantic Tiers
- **Void Canvas (`#050714`):** Primary background base; absorbs excess visual noise and provides infinite depth.
- **Cosmic Elevation (`#0b0f24`):** Secondary depth tier for underlays and recessed zones.
- **Electric Cyan (`#00f2fe`):** Primary action tier, focus rings, interactive states, and dimensional edge highlights.
- **Neon Violet (`#9b51e0`):** Secondary aura, thematic anchors, gradient transitions, and generative indicators.
- **Chromatic Magenta (`#ff007a`):** Tertiary spark, micro-accents, live experimental tags, and heat-map data points.

### Spectral & Glass Utilities
- **Glass Fill Base:** `rgba(11, 15, 36, 0.55)` layered over structural background nodes.
- **Glass Fill Elevated:** `rgba(255, 255, 255, 0.04)` over inner containers.
- **Prismatic Edge Gradient:** `linear-gradient(135deg, rgba(0, 242, 254, 0.6) 0%, rgba(155, 81, 224, 0.25) 50%, rgba(255, 0, 122, 0.6) 100%)`.
- **Text Primary:** `#f8fafc` (high-readability pure crystalline off-white).
- **Text Dim:** `rgba(248, 250, 252, 0.64)` for body clarity against variable blurs.
- **Text Ghost:** `rgba(248, 250, 252, 0.38)` for metadata and structural scaffolding.

## Typography
Typographic hierarchy relies on a strict trichotomy that balances technical rigor, modern digital elegance, and high-impact identity:

- **Display & Headlines (`Space Grotesk`):** Delivers sculptural, geometric authority with slight optical quirks suited for high-impact project titles and visionary manifestos.
- **Body Architecture (`Outfit`):** Geometric, ultra-clean, and highly legible against translucent, non-flat backdrops without creating eye fatigue.
- **Metadata & Technical Accents (`Space Mono`):** Fixed-width syntax grounding the creative work in technical craft—applied to experiment versions, coordinate stamps, metrics, status beacons, and categorical indices. Always rendered with subtle letter-spacing.

## Layout & Spacing
The layout follows a mobile-first fluid modular grid designed to accommodate viewport-constrained touch screens while maintaining breathing room for atmospheric backdrop glow phenomena.

### Layout Philosophy
- **Mobile Foundation:** 4-column fluid layout with a base 8pt linear rhythm, framed by `margin-mobile` (20px) to prevent refraction clipping along device edges.
- **Tablet Reflow (640px - 1024px):** 8-column layout. Portfolio items transition to staggered 2-column masonry grids.
- **Desktop Dynamic Scope (1024px+):** 12-column grid maxing out at `1280px` canvas width, centered, allowing radial ambient light engines to bleed freely into outer margins.

### Vertical Rhythm
- Maintain wide gaps (`space-2xl` to `space-3xl`) between distinct thematic showcases to let backdrop lighting signatures isolate themselves without muddying neighboring items.
- Micro-interactions, chip groups, and metadata clusters maintain tight sub-spacing (`space-xxs` through `space-sm`).

## Elevation & Depth
Depth in this system is strictly non-skeuomorphic; it relies on **optical refraction, backdrop diffusion, and chromatic emission**.

### 1. The Void Canvas (Level 0)
Flat, deep-space substrate (`#050714`) overlaid with two slow-moving, low-opacity radial gradient spheres (`#9b51e0` at 15% opacity and `#00f2fe` at 12% opacity) using blur radii > `120px`.

### 2. Frosted Floating Surfaces (Level 1)
Applied to portfolio cards, dynamic panels, and navigation modules:
- Background: `rgba(11, 15, 36, 0.65)`.
- Backdrop Filter: `blur(20px) saturate(180%)`.
- Edge Highlight: `1px solid rgba(255, 255, 255, 0.12)`.
- Ambient Shadow: `0 8px 32px 0 rgba(0, 0, 0, 0.45)`.

### 3. Iridescent Interaction Planes (Level 2)
Applied to hovered cards, selected modals, and focused modules:
- Background: `rgba(16, 22, 53, 0.75)`.
- Backdrop Filter: `blur(28px) saturate(200%)`.
- Border Treatment: 1px continuous border with an iridescent gradient angle running from Electric Cyan through Neon Magenta.
- Spectral Aura: Outer diffused glow using `0 0 24px -2px rgba(0, 242, 254, 0.35), 0 12px 40px -4px rgba(155, 81, 224, 0.25)`.

### 4. Overlays & Dimensional HUDs (Level 3)
Applied to sticky bottom navigation bars, full-screen project inspect drawers, and holographic overlays:
- Background: `rgba(5, 7, 20, 0.8)`.
- Backdrop Filter: `blur(32px) saturate(190%) contrast(110%)`.
- Top Edge Inset: `inset 0 1px 0 0 rgba(255, 255, 255, 0.2)`.

## Shapes
The design system embraces a **Pill-shaped (Level 3)** core contour vocabulary contrasted against disciplined structural containers. 

- **Primary Interactive Elements (Buttons, Badges, Search Inputs):** Fully pill-shaped (`border-radius: 9999px`) to reinforce a sleek, futuristic tactile aesthetic that feels like polished optical glass pellets.
- **Content Panels & Cards:** Styled with `rounded-xl` (`2rem` / 32px on desktop, scaling to `1.5rem` / 24px on mobile) to maintain organic fluidity while securing structural boundaries.
- **Micro-Indicators & Tech Tags:** Rounded capsules (`rounded-lg` / 1rem) to enclose monospace labels cleanly without visual weight imbalance.

## Components

### 1. Futuristic Pill Buttons
- **Primary Glow Button:** Fully rounded pill contour (`9999px`), base background of `linear-gradient(90deg, #00f2fe 0%, #9b51e0 100%)`. Text color `#050714` in `Space Grotesk` Medium. Dynamic shadow: `0 0 20px rgba(0, 242, 254, 0.5)`. On active press, scale translates to `0.97` with an intensified core magenta glow.
- **Glass Ghost Button:** Semi-transparent base `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(0, 242, 254, 0.4)`, text `#00f2fe` with an internal shimmer gradient animation on touch/hover.

### 2. Holographic Badges & Chips
- Monospace font (`Space Mono`, `label-code-sm`).
- Border treatment: Ultra-fine 1px border utilizing the tri-color gradient (`#00f2fe` -> `#9b51e0` -> `#ff007a`).
- Background: `rgba(0, 242, 254, 0.08)`.
- Lead icon or status dot: 6px circular neon beacon with pulse animation (`box-shadow: 0 0 8px #00f2fe`).

### 3. Glassmorphic Project Cards
- Shell: `backdrop-filter: blur(20px)`, dark translucent fill `rgba(11, 15, 36, 0.6)`.
- Border: `1px solid rgba(255, 255, 255, 0.08)`.
- Interactive Behavior: On mobile scroll into primary viewport center or cursor hover, the border dynamically blends into iridescent cyan-magenta, with an ambient colored shadow wash projecting behind the card.
- Inner Elements: Media visual container with rounded inner corners, overlay gradient scrim, and bottom metadata layout structured with monospace coordinates.

### 4. Interactive Lists & Feed Rows
- Unbordered list rows separated by horizontal hairline dividers: `linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.12), transparent)`.
- Row layout: Left-aligned index number in ghost monospace, followed by title in `Space Grotesk`, terminating in an illuminated cyan directional chevron.

### 5. Form Fields & Console Inputs
- Input Shell: Pill contour, background `rgba(255, 255, 255, 0.03)`, inset shadow `inset 0 2px 4px rgba(0, 0, 0, 0.6)`.
- Border: `1px solid rgba(255, 255, 255, 0.15)`.
- Focus State: Border transitions directly to Electric Cyan `#00f2fe` accompanied by an external bloom `0 0 12px rgba(0, 242, 254, 0.3)`.
- Caret: Custom glowing Electric Cyan cursor.

### 6. Toggle Switches & Radio Indicators
- Track: High-translucency capsule `rgba(255, 255, 255, 0.1)`.
- Thumb: Solid white or cyan reflective disc, elevated with `box-shadow: 0 0 10px #00f2fe`. Active track glows neon magenta.

### 7. Floating Holographic HUD Dock (Mobile Navigation)
- Fixed bottom persistent pill bar suspended `1rem` above viewport base.
- Ultra-dense blur: `backdrop-filter: blur(24px)`.
- Glowing active icon container with dynamic indicator bead beneath the active tab.

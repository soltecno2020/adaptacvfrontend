## Brand & Style

This design system embodies the intersection of computational precision, modern product design, and architectural clarity. Built specifically for an elite creative technologist, the interface acts as an invisible, high-fidelity gallery stage: crisp, quiet, and hyper-refined.

The personality balances computational rigor with organic luminance. It rejects sensory overload in favor of pristine spatial cadence, micro-scale textural details, and luminous emerald/mint focal points that signal state changes, live telemetry, and active experiments.

### Visual Movements
- **Hyper-Minimalism:** Generous macro-whitespace, restrained color dispersion, razor-sharp typographic scale.
- **Architectural Precision:** Hairline translucent dividers, disciplined grid alignments, and subtle layered porcelain planes.
- **Luminous Micro-Details:** Ambient emerald backlights, diffuse glows around active badges, and glass-polished surfaces that evoke physical laboratory optics.

## Colors

The palette is engineered around pure porcelain and crystalline whites, providing a light-filled canvas with high legibility. Deep graphite and slate typography anchor the layout without introducing harsh absolute black (#000000). Vibrant emerald and mint accents deliver surgical focal points for interactive affordances, live build indicators, and interactive prototypes.

### Palette Architecture
- **Base Canvas (`#f8fafc`):** Soft porcelain foundation minimizing glare while preserving warmth.
- **Elevated Canvas (`#ffffff`):** Pure crystalline white for project cards, floating panels, and interactive blocks.
- **Structural Outlines (`#e2e8f0` to `#cbd5e1`):** Micro-hairline delimiters maintaining order without visual clutter.
- **Typography & Content:**
  - Dominant Headline: Deep Slate Graphite (`#0f172a`)
  - Body & Secondary: Crisp Slate (`#334155`)
  - Metadata & Muted: Slate Fog (`#64748b`)
- **Accents & Telemetry:**
  - Primary Emerald (`#059669`): Interactive states, primary triggers, and anchor links.
  - Vibrant Mint (`#10b981`): Dynamic status beacons, glow halos, and live code indicators.
  - Emerald Tint (`#ecfdf5`): Ambient pill fill and subtle active states.

## Typography

Typographic hierarchy bridges technical craft and architectural poise through a three-family system:
1. **Space Grotesk (Headlines):** Imparts progressive technical authority with distinctive geometric ink-traps and structural tension.
2. **Geist (Body):** Ensures frictionless reading with neutral, human-scale geometry engineered for screen legibility.
3. **JetBrains Mono (Technical Metadata & Telemetry):** Provides rigorous alignment for dates, commit hashes, technology tags, and live telemetry badges.

All display titles enforce tight negative tracking to maintain punch and modern density, while all monospaced metadata runs uppercase with expanded letter-spacing for crisp scanning.

## Layout & Spacing

The layout is built on a responsive 12-column dynamic grid bounded by a max container width of `76rem` (1216px). Spacing utilizes an explicit 8pt baseline rhythm, allowing content to breathe with intentional architectural asymmetry.

### Breakpoints & Adaptive Rules
- **Desktop (1024px+):** 12-column grid with `gutter-desktop` (32px). Generous vertical padding (`space-4xl` to `space-3xl`) separates narrative case studies, letting media artifacts occupy primary focus.
- **Tablet (768px – 1023px):** 8-column grid with 24px gutters. Secondary columns collapse, transitioning multi-column data views into stacked modules.
- **Mobile (320px – 767px):** 4-column layout with `gutter-mobile` (16px). Outer page margins stay fixed at 16px to maximize readable area. Large interactive demos maintain a fluid aspect ratio (16:10 or 1:1).

## Elevation & Depth

This system avoids dark, muddy drop-shadows. Instead, elevation is communicated through **tonal transitions, translucent glass overlays, and delicate ambient backlights**.

### Elevation Stack
1. **Surface 0 (Base Canvas):** Porcelain foundation (`#f8fafc`). Non-elevated.
2. **Surface 1 (Card & Module Resting):** Crisp White (`#ffffff`) bound by a single hairline outline: `1px solid #e2e8f0`. Shadow: `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
3. **Surface 2 (Interactive Hover):** Translated `-2px` along the Y-axis. Hairline sharpens to `#cbd5e1`. Shadow: `0 12px 32px -4px rgba(15, 23, 42, 0.06), 0 4px 12px -2px rgba(15, 23, 42, 0.03)`.
4. **Surface 3 (Floating Overlays & Menus):** White at 85% opacity (`rgba(255, 255, 255, 0.85)`) with `backdrop-filter: blur(16px)` and border `1px solid rgba(226, 232, 240, 0.8)`. Shadow: `0 20px 40px -12px rgba(15, 23, 42, 0.08)`.
5. **Luminous Emerald Halos:** Interactive buttons and live status beacons project a soft, chromatic bloom: `box-shadow: 0 0 20px -2px rgba(16, 185, 129, 0.35)`.

## Shapes

The shape system adopts a refined balanced radius (`roundedness: 2`). This strikes an intentional equilibrium between structural machine aesthetic and tactile modern ergonomics.

- **Micro elements (Badges, Checkboxes, Micro-inputs):** `4px` to `6px` radius (`rounded-sm`).
- **Standard elements (Buttons, Input Fields, Code Blocks):** `8px` radius (`rounded-md`).
- **Containers & Project Cards:** `16px` radius (`rounded-lg`).
- **Floating Controls & Status Capsules:** Full pill format (`9999px`) to distinguish actionable controls from static layout containers.

## Components

### 1. Buttons
- **Primary Action:** Solid Deep Graphite (`#0f172a`) fill with Crisp White text. On hover, background shifts to Primary Emerald (`#059669`) accompanied by an ambient halo `0 0 24px rgba(16, 185, 129, 0.3)`. Border-radius is 8px; padding is 10px 20px; font is `Geist` 14px/500 weight.
- **Secondary Action:** Porcelain White (`#ffffff`) surface with 1px border (`#e2e8f0`) and slate text (`#334155`). On hover, border shifts to `#cbd5e1` with background `#f8fafc`.
- **Tertiary / Ghost:** Transparent background, slate text (`#64748b`). On hover, text turns to `#0f172a` with subtle background highlight (`rgba(15, 23, 42, 0.04)`).

### 2. Status Capsules & Telemetry Chips
- **Live Status Chip:** Pill shape (`9999px`), background `#ecfdf5`, border `1px solid rgba(16, 185, 129, 0.3)`. Text is JetBrains Mono 11px uppercase (`#059669`). Accompanied by a pulsating 6px circular mint beacon with a permanent `0 0 8px #10b981` glow.
- **Tech Stack Tag:** Rectangular pill (4px radius), subtle porcelain fill (`#f1f5f9`), border `1px solid #e2e8f0`, text JetBrains Mono 11px slate (`#475569`).

### 3. Project Cards (Work Artifacts)
- Pure white background (`#ffffff`), 16px radius, bounded by hairline `1px solid #e2e8f0`.
- Transition duration 250ms with `cubic-bezier(0.16, 1, 0.3, 1)`.
- Hover triggers subtle translateY (-3px), outer border shift to `#cbd5e1`, and a faint radial mint bloom positioned beneath the thumbnail view.

### 4. Input Fields
- Surface `#ffffff`, border `1px solid #cbd5e1`, 8px radius.
- Height: 42px with 14px `Geist` text (`#0f172a`).
- Focus state: Outline none; border shifts to `#059669` accompanied by a ring offset of `0 0 0 3px rgba(16, 185, 129, 0.15)`.

### 5. Code & Terminal Windows
- Embedded interactive prototypes feature a header toolbar with three 8px muted dots, an active Git branch indicator in JetBrains Mono, and a subtle horizontal divider (`#e2e8f0`).
- Background: `#fbfcfd` with selection highlight `#d1fae5`.

### 6. Lists & Index Rows
- Border-bottom: `1px solid #f1f5f9`.
- Flex arrangement: Left-aligned title in Space Grotesk, centered technical category in JetBrains Mono, right-aligned publication date or status dot.
- Hover applies full-row background wash `#f8fafc` with text color shift to `#059669`.
